# Design Principles

## Start with the job to be done

Write down the primary task in one sentence. Organize the screen around that task. A marketing page, music player, admin dashboard, editorial site, and documentation portal need different structures.

## Choose a visual direction

Select a small set of traits and translate them into decisions:
- Editorial: expressive typography, strong grid, generous whitespace, restrained color.
- Product/SaaS: clear hierarchy, compact navigation, strong states, precise spacing.
- Creative/portfolio: distinctive composition, intentional asymmetry, large media, concise copy.
- Commerce: product clarity, useful filters, trust signals, visible purchase path.
- Community/content: readable feeds, clear categories, strong search and contribution actions.
- Utility/tool: task-first layout, minimal distractions, obvious controls and feedback.

These are starting points, not rigid templates.

## Layout and hierarchy

- Establish a grid and consistent content width.
- Use alignment to create relationships.
- Give each screen one primary focal point.
- Use whitespace to separate groups; do not pad every component equally.
- Keep related controls close to the content they affect.
- Avoid nesting cards inside cards without a strong reason.
- Use full-width sections selectively; constrain long-form reading.
- Keep important content above decorative elements.

## Component composition

A component should have a clear purpose and predictable states. Reuse patterns for buttons, fields, navigation, dialogs, alerts, tabs, cards, and data displays. Reuse should improve consistency—not force unrelated content into identical cards.

## Content quality

- Write concise, specific headings.
- Use realistic sample content with varied lengths.
- Avoid generic filler such as repeated “Lorem ipsum” or meaningless KPI values.
- Use labels that explain what an item is and what happens next.
- Make empty states useful: explain why the area is empty and how to proceed.

## Avoid common AI-generated design habits

- Generic centered hero with two buttons on every project.
- Unnecessary gradients, glow, blur, and glassmorphism.
- Identical card grids for every section.
- Excessive rounded corners and pills.
- Tiny low-contrast gray text.
- Random decorative blobs and floating shapes.
- Fake charts, fake testimonials, fake customer logos, or fake metrics.
- Huge headings that push useful content below the fold.
- Navigation items that do not work.
- Desktop-only layouts squeezed onto mobile.

Use visual effects only when they reinforce brand, hierarchy, or feedback.
